# Local File Converter

A Shiny app for converting, sorting, merging, and renaming local files.  
Converted files are downloaded as a ZIP archive.

## Features

- Merge PDF files
- Convert JPG to PDF
- Convert PNG to PDF
- Convert JPG to PNG
- Convert PNG to JPG
- Sort files by type
- Sort files by modified date
- Rename files with optional:
  - prefix
  - suffix
  - find and replace
  - sequence number
